# Megha-App — Smart Farming & Soil Analysis Assistant

FarmSense (Megha-App) is a professional, high-performance Flutter mobile application designed for farmers. It features a liquid glassmorphism interface and integrates Google Gemini AI to analyze soil lab reports (images and PDFs), detect nutrient levels, auto-calculate soil health, and store reports persistently on the device for offline access.

## ✨ Features
- **Liquid Glassmorphism UI**: Farmer-themed color palette with zero-cost GPU glass cards.
- **AI-Powered Soil Analysis**: Instant parsing of soil report images/PDFs via Gemini AI API.
- **Nutrient Status Cards**: Visual indicators for Nitrogen, Phosphorus, Potassium, Calcium, Magnesium, Micronutrients, pH, EC, etc.
- **Complete Data Extraction**: Dynamic extraction of all lab parameters, customer/sample details, and recommendations.
- **Raw JSON Inspector**: View and copy full structured JSON extracted by AI.
- **Offline Local Storage**: Automatically saves analyzed reports to the device's storage with user deletion controls.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Sujayv1/Megha-App.git
   ```
2. Fetch dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
